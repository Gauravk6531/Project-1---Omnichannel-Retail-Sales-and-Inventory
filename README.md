# Retail Sales & Inventory Analysis

## Project Overview

This project analyzes retail sales and inventory data using Python and SQL to uncover business insights related to revenue, inventory management, product performance, and store operations.

## Week 1: Data Preparation

* Collected retail sales and inventory datasets.
* Cleaned and standardized data using Python (Pandas).
* Handled missing values and corrected data types.
* Converted date columns into proper datetime format.
* Exported cleaned datasets for analysis.

## Week 2: SQL Analysis & EDA

* Imported cleaned datasets into MySQL.
* Created relational database tables for sales and inventory.
* Performed SQL-based business analysis and validation.
* Conducted Exploratory Data Analysis (EDA) using Python.

## Key Findings

### Data Quality

* Sales and inventory records were fully aligned.
* No missing product references between sales and inventory tables.
* Database integrity was successfully validated.

### Sales Insights

* Weekend average daily revenue was higher than weekday revenue.
* Revenue trends showed fluctuations across the analysis period.
* Sales performance varied across products and stores.

### Inventory Insights

* Fast-moving products were identified for replenishment planning.
* Inventory records accurately tracked all sold products.
* Data supports future inventory optimization and forecasting.

### Business Insights

* Store comparisons are fair because all stores operate under the same sales channel.
* Product category analysis highlighted top revenue-generating segments.
* Profit KPIs were created using Sales Amount and COGS.

## Technologies Used

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* MySQL
* Jupyter Notebook

## Outcome

The project successfully transformed raw retail data into meaningful business insights, providing a foundation for inventory optimization, sales forecasting, and retail performance analysis.
